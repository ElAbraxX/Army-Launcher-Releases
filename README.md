# KryonCraft — descargas oficiales

[Sitio oficial](https://kryoncraft.pages.dev) · [Versiones y descargas](https://kryoncraft.pages.dev/versiones) · [Discord de KryonCraft](https://dsc.gg/kryoncraft)

KryonCraft es un launcher para **Minecraft: Java Edition en Windows de 64 bits**. Reúne en una sola aplicación las instancias de juego, los cargadores, los mods y los paquetes de recursos. Puedes preparar perfiles locales y, si lo necesitas, importar o mantener modpacks compartidos. Para jugar se requiere una cuenta Microsoft con Minecraft: Java Edition.

El proyecto sigue en desarrollo. Esta página guarda los **instaladores y archivos necesarios para actualizar KryonCraft**; no necesitas descargar el código ni los archivos técnicos por separado.

## Descargar e instalar

1. Consulta la [página de versiones de KryonCraft](https://kryoncraft.pages.dev/versiones) o la [última publicación de este repositorio](https://github.com/ElAbraxX/Army-Launcher-Releases/releases/latest).
2. Descarga el archivo `KryonCraft-<versión>-x64-Setup.exe` y ábrelo.
3. Sigue el instalador. Dentro de KryonCraft puedes buscar nuevas versiones desde el icono de actualizaciones de la barra superior.

Los archivos `latest.yml` y `.blockmap` son para el actualizador automático; **no hace falta abrirlos ni instalarlos**.

## Aviso de seguridad de Windows

Al abrir el instalador por primera vez, Windows puede mostrar **«Windows protegió su PC»**, **«Editor desconocido»** u otra advertencia de Microsoft Defender SmartScreen. También puede ocurrir con una versión nueva. El instalador usa un certificado propio autofirmado, que Windows puede no reconocer como editor de confianza. [Microsoft explica cómo influye la reputación del archivo y del certificado en estas advertencias](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation).

Antes de continuar, comprueba que descargaste el instalador desde los enlaces oficiales de arriba. Si reconoces el archivo y decides instalarlo, en la advertencia de SmartScreen puedes pulsar **«Más información» → «Ejecutar de todas formas»** cuando Windows ofrezca esa opción. **No desactives Microsoft Defender ni ignores una detección de malware**; si aparece una alerta diferente o el archivo vino de otro sitio, detente y consúltanos.
